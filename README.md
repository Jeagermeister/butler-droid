# Butler Droid

Butler Droid is an independent copy of the Maid mobile AI application that is
being maintained in this repository.

The source was initially copied from
[Mobile-Artificial-Intelligence/maid](https://github.com/Mobile-Artificial-Intelligence/maid)
under its MIT license. This repository is not a fork, mirror, or upstream
checkout; future development and releases are managed here.

## Development

Install dependencies with:

```bash
yarn install
```

Run tests with:

```bash
yarn test
```

Build Android with:

```bash
yarn build-android
```
